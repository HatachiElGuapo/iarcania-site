# Grandes Historias — catálogo de Void Stoic

Catálogo de trabajo para la serie **Grandes Historias** (área Void Stoic en
Brújula, objetivo "Grandes Historias"). Cada entrada es una historia con un
ángulo filosófico/estoico ya encontrado — el trabajo pendiente es pasarla a
guion y a HTML. Se actualiza a mano conforme se agregan, recortan o
descartan títulos; no es un registro de cambios, es la lista viva.

---

## Títulos con ángulo definido

Listos para guion — el ángulo ya está encontrado, falta ejecutar.

- **BOTW (Zelda)** — Zelda y los 4 Campeones como espejos; los sucesores
  rompen el patrón; los santuarios como el Vacío. Guion completo, refinado
  3 veces.
- **Berserk** — Guts encarna el aforismo de marca; la Bestia de Oscuridad
  como la sombra de Jung.
- **Iroh (Avatar)** — el maestro cálido; calma construida tras una pérdida
  real.
- **Zuko / Toph / Azula** — uno cada uno, sin resumen general.
- **Spider-Man, arco del simbionte** — la sombra de Jung; Fuego sin
  control.
- **Trilogía Arkham** — psique externalizada, identidad rota (Jason Todd).
- **Code Geass** — espejo de El Príncipe.
- **Fullmetal Alchemist** — el intercambio equivalente como dicotomía del
  control.
- **Red Dead Redemption 2** — Arthur Morgan, memento mori puro.
- **God of War (2018)** — Kratos: de Fuego sin control a Tierra.
- **Scarface** — pierde el imperio por no perder su humanidad.
- **Monster** — Johan y el doctor Tenma; el costo de una decisión.
- **Dishonored** — el único donde el juego mismo castiga la violencia
  (Caos).

## Con oro adentro, pero exigen recorte

El ángulo existe pero está dentro de una obra más grande — hay que aislar
la parte que sirve, no adaptar la obra entera.

- **Breaking Bad** — solo la inflación del ego de Walter.
- **Beastars** — el instinto de depredador como sombra a integrar.
- **Vegeta** — el orgullo transformado en propósito.
- **Gurren Lagann** — Kamina imprudente → Simon medido.
- **One Piece** — solo el Haki de Observación como Vacío.
- **Hunter x Hunter** — solo Meruem.
- **Juego de Tronos** — solo Ned Stark.
- **Steins;Gate** — solo Okabe cargando el peso solo.
